# 오컬트 서바이버 소개 자료

- 최근 갱신: 2026-10-27. 구형 갤러리 15장 중 14장을 최신 화면으로 교체하고, 지역 수집·심층 원정·무장 구성·선택 확인 4장을 추가했습니다. 최종 지역이 노출되는 결과 화면은 갤러리에서 제외했습니다. 현재 갤러리는 18장입니다.
- 촬영 소스: 2026-10-27 작업 소스의 임시 Android debug 빌드(versionName 0.49.14, versionCode 82). 같은 버전 번호의 기존 배포 APK보다 최신 개발 소스입니다. 이번 작업으로 배포 APK나 Play Console을 변경하지 않았습니다.
- 실제 Android API 36의 게임 Canvas 렌더러로 1080×2400 화면을 촬영했습니다. 일반 저장과 분리된 QA 환경에 촬영용 진행 상태를 구성했습니다. 웹 목업·호스트 렌더링·AI 합성 플레이 화면이 아닙니다.
- 촬영 검증: 19개 후보 화면, 4,756개 검사 통과. 버튼 겹침과 화면 영역, 번역 참조, 533개 디코딩 이미지, 일반 저장 보존을 확인했습니다. 이는 소개 이미지 촬영 검사이며 전체 게임 QA나 실기기 성능 보증을 의미하지 않습니다.
- 편집 범위: 원래 해상도·비율·UI 배치를 유지한 WebP 변환(품질 94)만 적용했습니다. 로딩 용량을 줄이되 글자와 픽셀 아트의 선명도를 육안 확인했습니다. UI를 합성하거나 다른 장면의 이펙트를 덧붙이지 않았습니다.
- 구형 파일명 01~14는 최신 이미지로 교체합니다. 16~19는 새 소개 화면입니다. 기존 15번 결과 화면은 `game.json`에서 제거하여 갤러리에 표시하지 않습니다.
- 배너: 기존 Google Play 소개용 키 아트(1024×500)를 유지합니다. 게임 프로젝트의 ImageGen 그림·영문 로고를 사용한 대표 이미지로, 실제 플레이 스크린샷과 구분합니다.
- 소개 순서: 타이틀 → 총기·마법·보스 전투 → 보상 선택·확인 → 서포터 → 장비·성장·구성 → 쉘터 → 작전·지도·수집·원정·기억 복원.
- 공개 상태: Android 개발 중. 확인되지 않은 출시일이나 공개 스토어 링크를 추가하지 않습니다. 공식 YouTube 영상이 없어 `videos: []`를 유지합니다.
- 이야기의 결말과 퍼즐 해법은 공개하지 않습니다. 99스테이지는 11개 지역의 전투 구성과 변형을 사용하는 본편 진행 수이며, 99개의 독립 제작 맵이라는 의미가 아닙니다.
- PC·Steam 출시 또는 온라인 협동·길드·클라우드 저장을 지원한다고 안내하지 않습니다.

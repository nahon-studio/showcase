# 대한민국 게임 이용등급 도안

게임콘텐츠등급분류위원회(GCRB)의 [공식 등급분류제도 안내](https://www.gcrb.or.kr/Institution/EtcForm01.aspx)에서 제공하는 GIF 원본입니다. 색상·문구·비율을 변경하지 않고 표시합니다. 도안 제공기관이 이 사이트의 게임을 심의했다는 의미는 아닙니다.

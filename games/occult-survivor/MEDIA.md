# 오컬트 서바이버 소개 자료

- 등록일: 2026-10-18
- 갤러리 확장: 2026-10-19, 실제 게임 화면 10장 추가(총 15장).
- 소개 상태: Android 개발 중. 공개 스토어 페이지가 아직 확인되지 않아 Google Play 링크는 비워 두었습니다.

- 스크린샷 15장: v0.49.4의 실제 Android Canvas 렌더러. 일반 저장과 분리된 QA 환경에서 촬영용 진행 상태를 구성했습니다. 전투 → 보상 선택 → 서포터·장비·능력치 → 쉘터 → 지역 탐사·기억 복원 → 결과 순서로 배치했습니다.
- 추가 화면: 낙뢰·메테오 전투, 지역 보스, 서포터 편성, 방어막·비행체·늑대 협공, 능력치 투자, 쉘터 시설, 쉘터 방어전, 지역 지도, 기억 복원실, 전투 결과. 결말 장면과 해법은 공개하지 않습니다.
- 촬영 검수: Android API 36, 1080×2400. 새 10장의 기본 UI 영역·버튼 겹침·번역 참조·일반 저장 보존 검사를 포함한 촬영 검증 2,663건 통과. 이는 소개 이미지 촬영 검사이며 전체 게임 QA나 기기별 성능 보증을 의미하지 않습니다.
- 이미지 처리: 원래 해상도와 화면 내용 그대로 WebP로 내보냈습니다. 원본 비율을 변경하거나 UI를 합성하지 않았습니다.
- 실행 플랫폼: Android. PC·Steam 출시 또는 온라인 협동·길드·클라우드 저장을 지원한다고 안내하지 않습니다.
- 99스테이지는 11개 지역의 전투 구성과 변형을 사용하는 본편 진행 수이며, 99개의 독립 제작 맵이라는 의미가 아닙니다.

# 요괴 타운 이미지 · 2026-10-27 현재 소스

- 갤러리 11장은 0.44.1 APK 캡처 재사용이 아닌, 2026-10-27 현재 게임 소스를 새로 컴파일·렌더링한 1600×900 개발 화면이다. APK/AAB를 빌드하지 않았다.
- Art, 콘텐츠·경제·전투 모델, 각 화면의 생산 코드와 현재 이미지 에셋을 사용했다. 마을·전투 그리기와 MobileUi HUD 메서드는 현재 소스에서 그대로 추출했다. Android Canvas 등 플랫폼 API만 Java2D로 대체했다.
- 본문 글꼴은 앱의 Typeface 설정과 동일하게 번들 NotoSansKR의 wght=500으로 인스턴스화했다. 글꼴 래스터화·그림자·색상 필터 등은 Android와 다를 수 있다. 기기 실행·성능·조작 검증을 뜻하지 않는다.
- 개발용 로컬 진행 상태를 준비했다. 실제 이용자·친구 데이터나 온라인 서비스 실행 화면이 아니다. 전투는 실제 Battle 모델의 출진과 260틱 진행 결과를 렌더링했다. 첫 보상도 실제 수확·목표 수령 함수를 거쳤다.
- 프롤로그, 길잡이, 보상 후 성장과 다음 행동, 생산 시설 상세, 보관함 상태, 세계지도, 요괴 성장, 저장 편성·배치 기록, 접이식 메뉴와 전투를 포함한다.
- 갤러리 alt·caption 및 소개 문단에 개발 중 소스 화면임을 명시했다. 기존 0.44.1 갤러리 6장은 현재 폴더에서 제거하고 Git 이력에 보존한다.
- 게임 목록의 표지는 최신 마을 화면으로 교체한다. 기존 banner-gameplay-v0441.webp는 영문 제목·캐릭터와 0.44.1 화면을 바탕으로 만든 홍보 합성물로 보존하며, 실제 최신 캡처로 설명하지 않는다. 원화 banner.webp도 보존한다.
- 게임 원본 리소스·소스·APK는 변경하지 않았다. 영상·스토어 주소·다른 게임 자료는 유지한다.

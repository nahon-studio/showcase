# 요괴 타운 배너 · 2026-10-18

- `banner-gameplay-v2.webp`: 큰 영문 `Yokai Town` 로고, 도깨비·여우 캐릭터, 마을 플레이 화면을 함께 보여 주는 홍보용 합성 배너.
- `cover-gameplay-v2.webp`: 게임 카드의 좁은 비율에서도 제목과 게임 화면이 보이도록 여백을 확보한 별도 표지.
- 기존 게임 홍보 그림과 실제 Android 마을 스크린샷을 입력으로 내장 이미지 생성 도구에서 합성했다. 화면 구성·UI 글자는 모델 합성 과정에서 일부 달라질 수 있으며, 원본 플레이 캡처 자체로 표기하지 않는다.
- 갤러리의 실제 플레이 스크린샷 4장과 기존 배너는 보존했다. 새 파일명으로 캐시를 구분한다.
- 웹 내보내기는 생성 결과의 원래 크기를 유지한 WebP 인코딩만 적용했다. 배너는 화면 전체를 채우며 `bannerFocus`로 중심을, `bannerTextPosition`으로 제목 위치를 조절한다.
- 공개 트레일러·스토어 링크 상태와 게임의 기능 설명은 유지한다.

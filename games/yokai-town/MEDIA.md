# 요괴 타운 이미지 · 2026-10-27

- 갤러리 6장은 Android 0.44.1 실행 검수에서 저장한 실제 1280×720 화면이다. 원본 구도를 유지해 WebP로 인코딩했으며, 화면을 생성하거나 합성하지 않았다.
- 순서: 마을 운영, 건설 배치, 원정 출진 준비, 원정대 편성, 장식 보관함, 타이틀.
- `screenshot-03-battle-v0441.webp`는 출진 위치와 부대를 선택하는 준비 화면이다. 실제 타격이 진행 중인 화면으로 설명하지 않는다.
- 기존 0.43.2 갤러리 4장을 교체하고 편성·보관함 화면을 추가했다. 이 캡처 이후의 미빌드 소스 수정까지 반영된 화면이라는 의미는 아니다.
- `banner-gameplay-v0441.webp`는 기존 영문 제목·캐릭터 그림과 0.44.1 마을 캡처를 바탕으로 내장 이미지 생성 도구에서 제작한 홍보용 합성 배너다. UI 글자와 세부 구성이 일부 달라질 수 있으므로 실제 플레이 캡처로 표기하지 않는다.
- 배너와 카드 표지는 같은 파일을 사용한다. 갤러리와 배너는 새 파일명으로 캐시를 구분한다.
- 교체한 구버전 스크린샷 4장과 이전 합성 배너·표지는 현재 폴더에서 제거한다. 이전 자료는 Git 이력에 남는다. 기존 원화 `banner.webp`는 보존한다.
- 공개 트레일러·스토어 링크 상태, 게임 기능 설명, 다른 게임 자료는 유지한다.
